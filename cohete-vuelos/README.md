# Cohete de agua: vuelos de prueba

Página para mostrar los videos del proyecto de Física 1.

## Estructura
```
index.html
style.css
script.js
videos/  vuelo1.mp4  vuelo2.mp4  vuelo3.mp4
img/     vuelo1.jpg  vuelo2.jpg  vuelo3.jpg
```

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube **el contenido** de esta carpeta (que `index.html` quede en la raíz del repositorio).
3. Ve a *Settings → Pages*, elige la rama `main` y la carpeta `/ (root)`, y guarda.
4. En un par de minutos tendrás el enlace `https://TU-USUARIO.github.io/NOMBRE-REPO/`.
